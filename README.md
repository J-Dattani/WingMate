# Wingmate: Your Society Management Solution

![Wingmate Logo](ico/Wingmate.png)

## Project Description
**Wingmate** is a comprehensive web-based platform designed to streamline and centralize the management of residential societies, high-rises, and apartment buildings.  

This project, developed as part of a **Semester 3 Web Technology** course, provides a robust solution for residents to effortlessly manage complaints, register vehicles, and access essential society information.

The application is built with a focus on **simplicity and efficiency**, aiming to bridge the gap between residents and the society's managing committee. Its modular design and foundational architecture make it highly scalable, allowing for the seamless integration of new features and functionalities in the future.

---

## Key Features

### 🛠 Complaints Management
- Dedicated and user-friendly portal for residents to **log and track complaints**.  
- System automatically populates user details *(owner name, wing, flat number)* ensuring a secure and verifiable process.  
- Complaints can be categorized.  
- Real-time status tracker provides **transparency** on issue resolution.  

### 🚗 Vehicle Entry System
- Simplified process for **registering personal vehicles**.  
- Residents can add vehicles with details such as *vehicle number, type, and model*.  
- Supports vehicle approvals and issuance of **society-specific parking stickers**.
